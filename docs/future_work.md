# AFLF Future Work

## Near-term research directions

1. Secure aggregation with stronger cryptographic guarantees.
2. Asynchronous federated learning for reduced round synchronization dependency.
3. Personalized federated learning for client-specific adaptation.
4. Hierarchical federated learning for multi-tier orchestration.
5. Trust scoring and robust client quality estimation.

## Evaluation expansion

1. Benchmark dataset expansion beyond current baseline datasets.
2. Larger client simulation scales.
3. Statistical validation with repeated trials and significance analysis.
4. Cross-dataset testing for generalization behavior.

## Engineering roadmap

1. CI-backed experiment health checks.
2. Reproducible containerized execution environments.
3. Versioned configuration schemas and migration tooling.
4. Automated experiment orchestration workflows.
